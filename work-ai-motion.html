E. ComfyUI 工作流详解 ComfyUI Workflow · LoRA · Tech Breakdown

01 / 总览

基于 ComfyUI 搭建的 LoRA 训练 + 推理一体化工作流：从原始角色素材清洗、Caption 标注、训练参数调优，到最终将 LoRA 注入 SDXL 基础模型完成批量出图。全程可视化节点编排，便于复现与迭代。

02 / 技术要点

核心技术栈包括 ComfyUI 节点式编排、SDXL 基础模型、LoRA（Low-Rank Adaptation）微调、ControlNet 姿态/线稿控制、Adetailer 人像精修，以及最终的高分辨率放大链路。

01 / 输入输出链路

输入：LoRA 训练集（10–20 张角色图 + Caption）、基础模型权重、正向/反向 Prompt、ControlNet 条件图。
输出：训练好的 LoRA safetensors 文件 + 批量推理结果图，可直接汇入 ComfyUI 下游用于角色一致性生成。

02 / 关键节点说明

  • 采样器 · Sampler：DPM++ 2M Karras / Euler a，步数 20–30，兼顾速度与细节
  • CFG 引导系数：一般 6.5–8.0，LoRA 权重较高时可下调至 5.5 避免过拟合
  • 重绘幅度 Denoise：角色一致性场景 0.3–0.5，风格迁移 0.6–0.8
  • 分辨率链路：512×768 基础出图 → Latent Upscaler → 1024×1536 精修
  • 放大链路：4× Ultrasharp / ESRGAN，配合 FaceDetailer 做人脸局部修复
  • ControlNet：OpenPose / Canny / Depth 三路并行，锁定角色姿态与构图

05 / AI 辅助环节

  • Prompt 生成与改写：使用 Coze AI 作为 Prompt 协作伙伴，快速迭代风格词与否定词
  • Caption 自动标注：BLIP / WD14 Tagger 批量打标，减少手动标注工作量约 70%
  • 素材清洗：通过相似度聚类剔除训练集中的重复与低质量样本
  • 结果评估：以 CLIP Score 与人工主观评分结合，筛选进入下一轮迭代的 LoRA
