原创海洋 IP 系列Marine IP Trio

三位海洋居民共享同一个海湾世界观，性格、色板、职业完全拉开，方便后续表情包与周边开发。

玳小园

玳瑁 · 园丁 · 焦糖棕 + 奶白

海湾里最年长的灵魂，独自打理整片珊瑚花园，随身挂着一把迷你修枝剪。焦糖棕与奶白的柔和配色，非常适合贴纸、胶带与帆布袋等周边延展。

汐小知

水母 · 预言家 · 紫蓝 + 半透明

漂浮在海湾最深处的紫蓝水母，据说能通过潮汐的节奏预见明日的天气与心情。半透明的身体自带光感，适合动画与表情包的发光特效。

蟹小满

螃蟹 · 工程师 · 暖灰蓝 + 锈橙

海湾里最忙碌的工程师，八条腿同时拧螺丝也不嫌多。暖灰蓝的壳配上锈橙的蟹钳，硬朗又讨喜，是三人组里的实干派担当。
