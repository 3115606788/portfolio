情绪小窝 · 轻小游戏 Mood Nest · Light Game

交互 · 情绪疗愈向 · AIGC 产图
玩法 & 贡献
  • 目标：记录 / 转化玩家的短期情绪，不追求胜负，追求「被接住」的感觉。
  • 界面结构：主页小屋 → 情绪选择 → 小事件反馈 → 房间装饰变化。
  • 负责：借助 AIGC 完成插画素材、氛围视觉生成并做细节优化；UI 风格板（雾蓝 / 米白 / 暖灰）、交互按钮动效、主要场景装饰元素。
  • 独立完成：页面搭建、交互逻辑与动态效果开发，打造沉浸式情绪陪伴。

演示视频

跑酷 + 校园元素：收集道具、避开障碍、到达终点触发校园地标彩蛋。

负责内容 / 贡献说明
  • 美术方向：角色模型贴图风格统一、场景道具 UI 三件套色板、HUD 图标。
  • 交互管线：主菜单 / 暂停 / 结算三端 UI 与按钮状态机、动效曲线一致。
  • 交付配合：演示视频分镜 + 录屏素材筛选剪辑、参赛 PPT 视觉统一。
  • 工作方法：把 Unity 工程拆成"可复用的 UI 组件"，保证后期替换成本最低。
