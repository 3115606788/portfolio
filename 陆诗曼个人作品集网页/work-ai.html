项目概述 Overview

以 ComfyUI 作为工作流中枢，把 Checkpoint、LoRA、ControlNet、放大节点、色彩一致性节点组织成可复用、可复现、可批量化的图生图管线； 再配合 Stable Diffusion WebUI 做快速迭代与 LoRA 选型测试，把"创意灵感 → 可重复管线 → 批量交付"整条链路打通。 另一条线是 AI Agent 工具搭建：在扣子平台独立完成面向短视频喜剧脚本创作的 Agent，从需求梳理、任务链路设计、Prompt 体系与知识库配置，到 BadCase 治理与多轮用户测试迭代，跑通"需求定义 → 原型上线验证"闭环。 这两条能力在约稿和竞赛里都是核心效率杠杆：能在不牺牲风格控制力的前提下，把出图速度提升 3-5 倍，同时把参数、节点结构与 Prompt 规范沉淀下来，变成可迁移的资产。

ComfyUI 工作流详解 Workflow Deep Dive

01 · 工作流类型
图生图（img2img）+ LoRA 风格嫁接

以草图/参考图为输入，保证构图与人物比例不漂；把"角色/质感/氛围"拆成多条 LoRA 并行控制，解决单模型风格单一问题。

02 · LoRA 模型与运用思路

习惯把 LoRA 分三层去用：底层（角色/脸型） 0.6-0.8 权重固定身份；中层（质感） 如胶片/水墨/莫兰迪色 0.3-0.5 做氛围； 顶层（细节） 如发丝高光、皮肤纹理 0.2-0.3 做点缀。工作流中会单独加入 LoRA 开关节点，便于 A/B 对比与调参。

04 · 输入输出对比

输入：草图 + 风格词（Mo Lan Di / Oriental ink / Cyber low saturation）。
输出：人物稳定 + 细节密度提升 + 噪点可控，可直接进入 AE 做二次创作。

05 · AI 辅助环节
  • 提示词模板库：把常用角色/氛围/光照词封装成一组组 Prompt 片段
  • 批次一致性：用种子锁定 + 小步长重绘，产出同系列几十张延展图
  • 多平台接力：即梦出人像 → WebUI 改色 → ComfyUI 合成 → 可灵 / Seedance 动起来
  • 项目复盘时保存完整工作流 JSON，下次项目可以直接迁移到新主题
